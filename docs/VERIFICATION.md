## 验收边界

原始问卷未包含在两个输入文件中，正式题库保持未发布。“豆豆”标准算例缺原始45个答案，尚不能验证该特定算例。浏览器测试题仅用于测试，不属于正式产品量表。

没有提供 Supabase 开发项目，因此尚未执行云端 Auth / Storage 联调、真实并发多连接压测、邮件投递与生产部署。数据库集成测试使用实际 PostgreSQL WASM 引擎，替代的是 Supabase 身份上下文，不是业务规则。原生照片选择与图片分享代码已类型检查，仍需 iOS / Android 真机验收。

Solo / Pack 执行流程、管理审核与主要页面已实现。运营参数、隐私协议正文和线下安全 SOP 仍需团队上线前确认。管理员审核采用单一管理员角色，细分运营岗位权限尚未配置。

## 主人需求与扩展时长

新增 6 项 PostgreSQL 集成测试，覆盖发布者身份与狗狗归属、无效时间和时长、重复发布、狗狗已有需求冲突、公开信息白名单、专用时段不可复用、接单权限与竞争接单后的拒绝、接单重试幂等、任务交接资料权限、已发布时段冲突、取消释放日历、未接单临近开始时撤回、过期和停用主人的需求不可接单，以及更长服务时长不能超过时段长度。

浏览器验收已通过：六档时长显示、90 分钟需求发布、公开列表不含详细交接地址、接单后任务和订单确认、任务内查看交接时间及地址、取消已接单需求、撤回未接单需求，以及选择较短时段时隐藏超长选项。原有运营指派、Pack 申请、测评草稿与分享、遛狗师发布时段和演示登录回归均通过。TypeScript、Next.js 构建、Expo Web 导出、AGENTS 规则检查通过；390px 需求广场和发布表单已目视检查。
