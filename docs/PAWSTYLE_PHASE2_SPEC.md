# 交给 Codex 的任务：DOGO PawStyle 第二阶段

上一阶段的选择题展示、作答和持久化已实现。本次**不要重做问卷**，仅新增“计分 + 性格标签 + 结果页 + 四张临时狗狗画像”。

## 输入文件
- `pawstyle-scoring.ts`：独立 TypeScript 参考实现（无第三方依赖）。请适配项目现有代码/技术栈，并接入现有 D1–D45 答案结构。
- `pawstyle-image-manifest.json`：四种类型名称、临时图片映射及展示规则。
- `public/images/pawstyle/*.png`：四张现有卡通狗狗原图，复制到项目对应静态目录（注意构建工具的 public 规则）。

## 计分与结果
1. 核心 45 题取原分 1–5；14 道反向题使用 `6-x`：D1 D4 D9 D10 D11 D18 D19 D22 D26 D28 D29 D34 D38 D41。`X`/未答视为缺失，不做 0 分、中间分或插值。
2. 15 个分面各 3 题，必须 3 题有效才计算均值。五因子需所属所有分面完整才给出均值；完整度展示 45 题有效数。反向计分后再算均值。
3. E=兴奋性=(D15+D31+6-D41)/3，P=玩耍倾向=(6-D9+D17+D33)/3。E/P 缺失 -> 风格待补充；E 或 P 恰好为 3 -> 混合倾向；其余依据 >3、<3 输出 EP Spark 热情玩伴型、CP Sunny 平和玩伴型、EL Scout 活跃观察型、CL Cloud 悠然观察型。
4. E 或 P 落入 2.5–3.5（且非 3）时显示“接近分界，倾向轻微”。分类用未四舍五入分，数值显示保留两位小数。
5. 结果页展示：正式性格名称（若可分类）、E/P 两轴分数、基于两轴的文字标签、五维 F1–F5（1–5）、完整度、观察基础提示及版本。五维可以额外换算 0–100：`(mean-1)/4*100`，但不得称为准确率/百分位/概率，不生成“好狗总分”。
6. B1、B2、B4、B6 可用来给出观察基础提醒：B1 少于 1 个月、B2 每周不足 3 天、B4 多为印象或 B6 近期有变化时，提示“观察基础有限或近期状态可能影响结果”；不能直接减分。
7. 保持 S1–S5 独立存储，涉及咬人/咬狗、护物、逃脱、紧张等情境的事件不能被人格均分覆盖。人格类型**不能作为 Pack 自动安全放行依据**。不得凭“Scout”推断聪明、观察能力强，或凭“Sunny”推断喜欢陌生狗。
8. 保留原始答案 + 反向处理后的答案 + 15 分面 + 五因子 + E/P + 风格代码 + 完整度 + 版本。复测建新记录，不覆盖旧记录。数据与 UI 中文一致。

## 图片导入重要说明
- 临时使用本包图片，但原图底部的英文标题是艺术展示标题，不等于正式问卷类型（例如 EP 图片底部原写 Energetic/Adventurous）。**UI 必须只展示正式类型名**；图片建议放在 `aspect-ratio: 4 / 3; overflow: hidden;` 的上方裁切容器内，图片 `width:100%; height:100%; object-fit:cover; object-position:center top;`，从视觉上隐藏原图底部标签。实际 CSS/组件按框架适配。
- 图片对应：EP `EP_Spark.png`；CP `CP_Sunny.png`；EL `EL_Scout.png`；CL `CL_Cloud.png`。
- 混合倾向/待补充**不可擅自分配四张类型图**，请使用已有 DOGO logo/通用占位图。
