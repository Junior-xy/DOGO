# DOGO 视觉依据

使用用户提供的原始 logo，不重新绘制。浅金色狗狗、橙色牵引和黄绿色草地构成视觉来源；卡片和输入控件延续 logo 外框的柔和圆角。

`packages/ui/src/tokens.ts` 统一保存配色、间距、字号和圆角。深绿色 #427044 用于主要操作与导航，确保浅色背景上的可读性；浅绿 #D7EC9F 和浅黄 #FBDD90 用于背景而非小字号正文。橙色 #FF9E4D 用于焦点强调。正文使用深灰绿 #292D23，降低纯黑的生硬感。

移动端以狗狗档案、Dogo Ti、Solo、Pack、订单为信息中心。管理端以待办预约、审核和异常为优先，避免用无依据的统计数字填充界面。未接入后端时清楚提示环境配置；未发布问卷时不展示虚构题目和分数。

Logo 保留原样，小尺寸用于品牌识别，首页使用一次较大的图像。没有额外生成插画。
